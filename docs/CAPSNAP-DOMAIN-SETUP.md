# Multi-domain note (historical)

**Fotomatic** is now a **separate repository and deployment** from Grad Drive. This project no longer uses middleware to serve Fotomatic on a second domain.

- **Grad Drive** — primary app (this repo): user dashboard, admin, photographer portal at `/photographer-admin`, etc.
- **Fotomatic** — standalone Next.js app: see your `Fotomatic` project folder / GitHub repo.

To send users from Grad Drive to book photographers on Fotomatic, link to your Fotomatic production URL (e.g. `https://fotomatic.app/photographers`) from marketing pages or the dashboard as needed.
